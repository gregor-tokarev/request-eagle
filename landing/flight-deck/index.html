The API client that gets out of the way.

Request Eagle is a native Postman alternative built in Rust. Your requests live as TOML files on your disk, and the app never asks you to sign in.

Features

Everything for the request. Nothing else.

Collections, environments, scripts and tests, in an interface that draws every frame on the GPU.

Requests are files

Every request is a TOML file inside ~/.request-eagle/collections. Commit them, review them in a pull request, or edit them by hand.

Flight API / Flights / List flights.toml
name = "List flights"
schema_version = 1

[request]
type = "http"
method = "GET"
path = "{{base_url}}/v1/flights"
headers = [["Authorization", "Bearer {{token}}"]]
query = [["status", "airborne"], ["limit", "25"]]

Collections and folders

Nest folders as deep as your API goes. Filter by name, method or URL.

GET POST PATCH DELETE

Variables that complete themselves

Type {{ in a URL, header, query or JSON body. Pick from the collection's environment.toml or generated values such as {{$guid}}.

Vim mode

Motions, operators, counts, Visual mode and / search in the body and script editors. Off by default, one switch in Settings.

Keyboard first

Eleven theme families

Ayu, Catppuccin, Gruvbox, Everforest, Flexoki, Solarized and more, each in light and dark. Follow the system appearance or pin one.

Responses of any size

Bodies past 10 MiB still scroll and search in full. Hover the status, time or size for a breakdown of where the milliseconds went.

Scripting

Scripts you already know how to write.

Pre-request and post-response JavaScript with a familiar pm.* API.

  • Chain requests Await pm.sendRequest to fetch a token, then attach it to the request being sent.
  • Test every response Assertions and JSON Schema checks, reported beside the response.
  • Sign and encode SHA-256, HMAC and Base64 helpers for signed APIs.
  • Typed completion A bundled TypeScript service suggests APIs and parameters. No Node.js required.
Agent CLI

Hand your collections to an agent.

An optional standalone binary lets AI agents list, edit and run saved requests with JSON commands. It needs no token, daemon or running app.

request-eagle-cli
# Discover every command and its schema
$ request-eagle-cli schema

# Find a saved request
$ request-eagle-cli call '{"command":"requests.list","query":"health"}'

# Run it
$ request-eagle-cli call '{"command":"requests.run","path":"/absolute/path/Health.toml","timeout_ms":10000}'
