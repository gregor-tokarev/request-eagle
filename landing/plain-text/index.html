Your API requests are just files.

Request Eagle is a native API client for macOS. Every request is a TOML file on your disk, so your collections work with git, code review and any editor you like.

Principles Five decisions behind the app
1

Files you own, in a folder you choose.

Collections are folders. Requests are TOML. Variables live in an environment.toml beside them. Nothing syncs to a server, and nothing asks you to sign in.

A changed header shows up in git diff as one changed line.

git diff
--- a/Flight API/Flights/List flights.toml+++ b/Flight API/Flights/List flights.toml@@ -6,3 +6,3 @@ method = "GET"-path = "{{base_url}}/v1/flights"+path = "{{base_url}}/v2/flights" headers = [
2

Native, not a browser in a box.

Request Eagle is written in Rust and draws its interface on the GPU with GPUI. The download is 19 MB.

Large responses stay usable. Bodies over 10 MiB scroll and search in full, because only the visible rows are laid out.

3

Hands stay on the keyboard.

Every shortcut can be rebound. Vim mode brings motions, operators and Visual mode to the body and script editors.

  • Send request ⌘ ↵
  • Save request ⌘ S
  • New tab ⌘ T
  • Close tab ⌘ W
  • Search collections ⌘ F
  • Jump to tab ⌘ 1–9
4

Scripts when a request needs logic.

Write JavaScript that runs before a request or after its response, using a familiar pm.* API. Fetch a token, sign a body, assert on the result.

The editor completes APIs and parameters with a bundled TypeScript service, so there is no Node.js to install.

A pre-request script fetches the token. Two tests check the response.

5

Ready for agents.

An optional command-line tool gives AI agents the same collections. It lists, edits and runs saved requests with JSON commands, without the app running.

Terminal
# Find a saved request, then run it
$ request-eagle-cli call '{"command":"requests.list","query":"health"}'
$ request-eagle-cli call '{"command":"requests.run","path":"/absolute/path/Health.toml"}'
Details What is in the box today
Requests GET, POST, PUT, PATCH, HEAD, OPTIONS and DELETE with params, headers, JSON or raw bodies.
Variables Collection environments, plus generated values such as {{$guid}} and {{$isoTimestamp}}. Type {{ to complete.
Responses Formatted JSON, headers, cookies, test results, console output and a timing breakdown.
Network HTTP version, timeouts, redirects, certificate verification and proxy settings. Proxy credentials go to the system keychain.
Appearance Eleven theme families in light and dark, an editor font of your choice, and interface sizes from 12 to 24 px.
Platforms macOS on Apple Silicon, signed and notarized. Linux builds from source.
Status Early development. New builds ship most days, and updates install from inside the app.
