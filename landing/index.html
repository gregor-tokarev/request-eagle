Fast is a feature.

Request Eagle is a Postman alternative written in Rust and rendered on the GPU. It is a real Mac app with no web view inside, and it keeps your requests as files on your disk.

Your disk.
Your git.

Every request is a TOML file in a folder you control. There is no account, no sync service and no export step.

  • Collections and nested folders
  • Environments in environment.toml
  • Search by name, method or URL
# Flight API / Flights / List flights.toml
id = "3f1c9a52-7e4b-4d1a-9c55-0b6e2a8d41f7"
name = "List flights"
schema_version = 1

[request]
type = "http"
method = "GET"
path = "{{base_url}}/v1/flights"
headers = [["Authorization", "Bearer {{token}}"]]
query = [["status", "airborne"], ["limit", "25"]]

Script it.
Test it.

Pre-request and post-response JavaScript with a familiar pm.* API. Results land next to the response.

  • Chained requests with await pm.sendRequest
  • Assertions and JSON Schema checks
  • SHA-256, HMAC and Base64 helpers
  • Typed completion, no Node.js needed

Never leave
the keys.

Send with ⌘↵ from anywhere in the request. Rebind any shortcut, and switch on Vim mode for the body and script editors.

  • Vim motions, operators, counts and Visual mode
  • Variable completion when you type {{
  • Generated values such as {{$guid}}

Agents
welcome.

An optional CLI gives AI agents the same collections. It speaks JSON, describes its own schema and runs without the app. 

$ request-eagle-cli schema

$ request-eagle-cli call \
    '{"command":"requests.list","query":"health"}'

$ request-eagle-cli call \
    '{"command":"requests.run",
      "path":"/absolute/path/Health.toml",
      "timeout_ms":10000}'
